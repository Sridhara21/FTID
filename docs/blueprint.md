# **App Name**: FTID Vision

## Core Features:

- Citizen FTID Wallet: Secure digital wallet for citizens to manage FTID transactions.
- Dual-Party Transaction Logging: Log FTID transactions between citizens and government entities using blockchain principles.
- AI Financial Advisor: AI-powered tool offering basic budgeting and personalized savings tips.
- Credit Score Builder: Monitor and provide recommendations to improve citizens credit scores.
- Auto-Tax Calculator: Automatically calculate taxes based on logged FTID transactions.
- Real-Time GDP Tracking: Track real-time GDP based on aggregated FTID data. Includes historical and export functionality
- Fraud Detection Heatmaps: Visualize potential fraud hotspots through interactive heatmaps.

## Style Guidelines:

- Primary color: Sky blue (#67B9FF) to evoke trust and stability.
- Background color: Light grey (#F0F4F7), providing a clean and modern backdrop.
- Accent color: Sea green (#3CB371) to highlight important data points and calls to action.
- Body and headline font: 'Inter' sans-serif for clear readability and modern aesthetics.
- Use flat, geometric icons with subtle animations to represent financial data and transactions.
- Dashboard layouts designed for clarity, using graphs and charts to present key data insights in a user-friendly way.
- Incorporate subtle animations and transitions to enhance user engagement and provide visual feedback during interactions.
